## 技术备注

- apiyi `gpt-image-2-vip` 价格：$0.03/张，所有 size 统一价
- 1K Fast 720x1280 = 最稳草稿档（~30-60s）
- 2K Recommended 1152x2048 = 高峰期不稳定（~90-120s）
- gpt-image-2-vip 不支持 `quality` / `n` 参数
- imageGenerationModel.primary / timeoutMs 是 protected config path（不能 gateway config.patch 改）
- WebChat 不渲染 MEDIA: 指令 → 用 `open` 命令或 canvas 工具看图
