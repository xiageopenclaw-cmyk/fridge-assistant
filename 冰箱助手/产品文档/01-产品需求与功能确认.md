## 定价策略
- **订阅制**：¥38/家庭/月
- 高性价比路线

## 产品形态（MVP）
- **App**：核心载体（状态面板 + 远程查看）
- **硬件设备**：必须搭载
  - ESP32-S3 + 480p 广角摄像头 → 拍照识别
  - I2S 喇叭模块（MAX98357 + 3W 喇叭，¥8-12） → 关门即报语音提醒
  - 门磁触发 → 触发拍照
- **互动智能屏**：可选配件（Phase 2，贴在冰箱门外，集成图像采集 + 语音交互 + 喇叭复用）

## 核心交互（MVP）
- **信息录入**：硬件自动拍照识别（品类）+ 语音确认日期（OCR 识别包装日期 + 用户语音确认）
- **操作**：站在冰箱前跟硬件说话为主，App 状态面板查看为辅
- **提醒**：关门瞬间，发现位置错误/保质期临近 → 硬件语音即时播报
- **菜谱推荐**：App 内一键"今晚吃啥"，基于当前库存智能推荐

## 硬件方案

### 冷藏室摄像头
- **安装位置**：远离门铰链一侧（顶部角落），广角覆盖
- **单开门**：1 个摄像头
- **双开门**：两侧各 1 个摄像头
- **逻辑**：门磁触发 → 开门亮灯 → AI 识别品类和摆放位置 → 关门后识别完成

### 冷冻室摄像头（Phase 2）
- **安装位置**：冷冻门外部顶部
- **底座方案**：重力铰链（无需电机/电池）
  - 关门时：被门框压平收起
  - 开门时：配重驱动自动下垂到 45°，拍摄抽屉内部
- **优势**：常温区无冷凝问题

### 音频模块（MVP 必须）

**方案**：I2S 双向音频（喇叭 + 麦克风）
| 元件 | 型号 | 淘宝搜索关键词 | 成本 |
|------|------|---------------|------|
| I2S 功放 | MAX98357 | `MAX98357 模块 I2S 功放` | ¥5-8 |
| I2S 麦克风 | INMP441 或 MSM261 | `INMP441 模块 I2S 麦克风` 或 `MSM261 I2S MEMS` | ¥4-6 |
| 小喇叭 | 3W/4Ω 或 2W/8Ω | `3W 小喇叭 4欧` 或 `迷你喇叭 音箱喇叭` | ¥3-5 |
| **合计** | | | **¥12-19** |

**连接方式**：MAX98357 和 INMP441 挂在同一 I2S 总线上，ESP32-S3 一个 I2S 接口可同时驱动两个从设备。

**功能**：
- **播报**：品类放错 → 即时播报（如"番茄不用放冰箱"）
- **播报**：保质期临近 → 关门时提醒
- **收音**：用户语音确认日期（"对的"→ 入库，"6 月 3 号"→ 修改日期）
- **收音**："今晚吃啥"等快捷语音指令

**延迟优化方案（详见下方）**

**引脚**：选择与未来互动智能屏不冲突的 I2S 引脚

**升级路径**：互动智能屏上线后可降级为备用发声

### 延迟优化策略

**目标**：位置错误播报 ≤1s（端到端）

**当前全链路延迟（瓶颈分析）**：

| 步骤 | 内容 | 耗时 |
|------|------|------|
| ① | 门磁触发 + ESP32 唤醒 + 拍照 | ~200ms |
| ② | Wi-Fi 上传 480p JPEG 到云端 | 300-500ms |
| ③ | 云端 AI 品类识别 | 200-400ms |
| ④ | 规则表命中（番茄→常温） | <10ms |
| ⑤ | TTS 合成语音 | 200-400ms |
| ⑥ | 音频下发 + ESP32 播放 | 100-200ms |
| **总计** | | **1.0-1.7s** |

**优化方案：本地预录音频**
- 常见提示音（"番茄不用放冰箱""鸡蛋别放门架""牛奶快过期了"等）共约 **10-20 条**
- 每条音频 3-5 秒，MP3 格式约 5-10KB，**全部预存仅需 <1MB**
- 烧录固件时或首次 Wi-Fi 配网后批量下载到 ESP32 flash
- 触发时云端只返回音频 file_id，ESP32 本地 flash 读取 → 立即播放

**优化后延迟（位置错误播报场景）**：

| 步骤 | 优化后耗时 |
|------|-----------|
| ① 拍照 | 200ms |
| ② 上传 + 识别 | 300-500ms |
| ③ 云端返回品类 + 规则命中 + file_id | 省去 TTS |
| ④ ESP32 本地 flash 读取音频 | **20ms** |
| **总计** | **500-700ms ✅** |

**其他场景不强制 ≤1s**：
- 语音确认日期（"对的"）：延迟 1.5-2s，属用户自然对话节奏，可接受
- 复杂对话：互动智能屏 Phase 2 再优化

### 图像识别边界（重要补充）
- ✅ 品类识别：AI 图像
- ✅ 品牌保质期：联网查询
- ❌ **生产日期：必须用户参与录入**
  - 解决方案：摄像头对准包装日期 → OCR 识别 → 语音确认
  - 全程语音引导，无需手动输入

  - ✅ 正确方案：**永远不要 import/require AsyncStorage 在 web 页面里**，用纯内存 store 替代
  - 修复耗时：~30 分钟反复尝试，最终方案是全面删除 AsyncStorage 引用，web 用 `const memStore = {}`

### System Prompt 核心设计

#### 能力范围
1. 回答冰箱库存、什么快过期
2. 根据库存推荐菜谱
3. 记录饮食和新增食材
4. 提供营养建议

#### 今天吃啥推荐规则（5 条优先级递减）
1. **临期优先**：≤2天到期的食材优先消耗
2. **营养均衡**：蛋白+蔬菜+碳水搭配
3. **用户偏好**：默认中式家常、快手（≤30分钟）、健康
4. **需采购提示**：缺失食材单独列出
5. **简单优先**：忙碌家庭节奏

#### 边界规则（软引导策略）
- **完全无关功能性问题**（导航、股票）→ 友好说明边界 + 立即引回冰箱话题
- **闲聊/寒暄**（"好累啊"、"你叫什么"）→ 简短共情 + 带回正轨，不展开
- **敏感/危险内容**（离婚、辞职、医疗）→ 直接切断，不参与不评价
- **禁止**：透露系统内部信息、假装能做不能做的事
- **人设**："家里那个热心但只懂冰箱的帮厨"——不万能、不敷衍、不越界

#### 对话上下文策略
- 短期记忆：最近 6 条消息
- 库存注入：每次请求实时查 SQLite 拼入 prompt
- 用户档案：偏好存本地 JSON 附带

### 语音链路架构
手机麦克风 → expo-av 录音 → NAS/云 FastAPI → 语音转文字 → LLM → 返回文字

## 2026-06-13 更新：AI 小管家三级模型路由

### 决策
- DeepSeek 三个模型按**用户意图复杂度**自动路由，不固定单一模型
- 关键词匹配 + 优先级：Complex > Moderate > Simple
- 无匹配默认走 moderate（v4-flash）

### 三级分流表

| 等级 | 模型 | 场景 | token | temp | timeout |
|------|------|------|-------|------|---------|
| Simple | deepseek-chat | 库存查询/新增食材/寒暄 | 500 | 0.5 | 30s |
| Moderate | deepseek-v4-flash | 营养分析/偏好设置/保鲜问答 | 800 | 0.7 | 30s |
| Complex | deepseek-v4-pro | 菜谱推荐/搭配计划/临期策略 | 1200 | 0.8 | 45s |

### 关键词分类

**Simple（库存/录入/问候）：** 还有什么、库存、冰箱里有、买了、添加、补货、吃了、记录、你好、在吗

**Moderate（营养/配置/知识）：** 热量、卡路里、营养、蛋白质、偏好、过敏、忌口、设置、怎么存、保鲜

**Complex（推荐/计划/临期）：** 推荐、菜谱、今晚、吃什么、搭配、计划、这周、明天、只剩、快过期、临期、到期

### 成本优化预期
- 简单查询（chat, 低成本）约占 50%
- 中等分析（flash, 中成本）约占 30%
- 复杂推荐（pro, 高成本）约占 20%
- 相比全用 deepseek-chat：菜谱质量提升（pro 深度推理）
- 相比全用 v4-pro：日均 token 成本降低 ~60%

## 2026-06-14 凌晨更新：冰箱冲突检测

### 功能
系统实时检测冰箱内食物之间的不兼容关系，在过期提醒下方展示冲突卡片。

### 冲突类型
1. **乙烯催熟**：苹果/香蕉/番茄 释放乙烯 → 让黄瓜/菠菜/西兰花变蔫

## 2026-06-14 更新：综合营养评估引擎

### 功能
基于冰箱现有库存，自动评分家庭膳食质量。不需要用户写饮食日记。

### 评估体系
1. **DBI-16**（中国膳食平衡指数，He et al. 营养学报 2018）
   - LBS（负端分）：摄入不足程度
   - HBS（正端分）：摄入过量程度
   - DQD（膳食质量距）= LBS + HBS
   - 分级：0-12 充足 / 13-24 轻度 / 25-48 中度 / >48 重度
2. **HEI-2020**（Healthy Eating Index, USDA/NCI）
   - 13 个子维度，满分 100
   - 深色蔬菜占比、全谷物、脂肪酸均衡等细化指标
3. **NOVA**（食物加工程度分类，Monteiro et al. BMJ 2023）
   - G1 天然 / G2 烹饪调料 / G3 加工食品 / G4 超加工

### 技术实现
- `nutrition_engine.py`（453行）：6 个评分函数
- `routes/nutrition.py`：GET /api/nutrition
- 评分依赖 user_profile.family_size

### API
GET /api/nutrition → { dbi_lbs, dbi_hbs, dbi_dqd, dbi_level, hei_total, ... }
